Save slots

3 local slots · nothing leaves the device
  • Each card shows where you are in the story, not just a percentage: stage, place, Scrolls, Light, playtime.
  • Erase needs a 1.5 s hold with a filling bar, so a child cannot wipe a parent's game with one tap. No pop-up dialog.
  • Empty slot starts the opening scene directly.

World map

The road itself · left to right
  • Nine waystations on one illustrated road. Completed stages show a lit lantern (moss), the current one glows gold, locked ones are dim but named.
  • Any finished stage can be replayed to find missing Scrolls.
  • Selecting a stage opens the info card; "Walk on" starts it.
  • On wide screens the map gains sky and margin; the road never stretches.

Pause

Overlay · game frozen behind
  • Resume is first, largest and focused. The pause button, Menu on a gamepad, or Esc also resumes.
  • "Return to map" is set apart and coloured ember. It asks once, inline on the card: "Progress since the last waystation will be lost."
  • The game auto-pauses when the app goes to the background or a controller disconnects.

Settings: Accessibility

4 tabs · each option explains itself
  • Text size shows a live dialogue sample beside the control, so the choice is visible before you leave.
  • The focused row shows its one-line description below the list.
  • Sound tab: Music, Effects, Voice sliders (0 to 10). Display tab: fullscreen (desktop), pixel scale lock.
  • Settings are global, not per save slot.

Settings: Controls (touch)

Edit in place over a live level
  • Buttons are moved by dragging on top of a running sample level, so players see exactly what they will get.
  • Every hit area is at least 24 game px (48 pt on the smallest phones), inside the safe area, never under the home bar.
  • Stick or D-pad toggle; left-handed swap; Block appears only after stage 5.
  • Gamepad and keyboard tabs show the bindings; keyboard keys can be remapped (physical key codes).

Not in the required list, included for context
